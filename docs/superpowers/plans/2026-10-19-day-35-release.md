# Day 35 release assistant implementation plan

> Execute inline with superpowers:executing-plans. User authorized end-to-end implementation, PR and launch.

**Goal:** automate release preparation from real Git changes with direct DeepSeek.
**Architecture:** bounded read-only Git evidence → validated AI JSON → Markdown preview/export; local HTTP UI.
**Tech Stack:** Python 3.10+ standard library, shared/llm.py, Git, buildless HTML/JS.
**Spec:** days/day-35-release/SPEC.md.

## Global constraints
No browser automation; no publish/tag/push by service. No new dependencies.
Only fixed export directory, immutable selected SHA, no secret-bearing diff to AI.
AI citations must match actual commits, no claims of executed tests.

## Review focus
Invalid refs/options, secret-bearing diffs, excessive evidence, invalid AI JSON/citations,
stale async replies, double saves and filename traversal.

## Tasks
- [x] Git evidence and release engine: tests for ancestor SHA, limits, exclusions,
  AI schema/citations, Markdown/export; release.py implements the contract.
- [x] HTTP/UI: :8035 base/head/task form, async progress, evidence, release notes,
  download/save. Tests for bounded jobs, origin/path/schema and exact export readback.
- [ ] Live smoke, docs, CI, independent read-only review, PR from current main, launch.
