# Day 34 File Assistant Implementation Plan

> Use superpowers:executing-plans. End-to-end implementation and PR publication
> are authorized by the user's standing instructions in this conversation.

**Goal:** An assistant that autonomously reads and edits project documentation.
**Architecture:** goal → model tool loop → scoped MCP workspace → staged diff →
explicit apply. Deterministic demo exercises the same actual MCP operations.
**Tech Stack:** Python 3.10+ standard library; shared MCP and LLM transport.
**Spec:** days/day-34-files/SPEC.md

## Global Constraints
No browser, no code execution/deletion. Text-only reads; Markdown-only writes.
Root confinement, protected files and symlinks rejected. At least three read files.
Preview by default, explicit --apply, optimistic SHA checks and atomic per-file writes.
Bounds: 300 paths, 80 matches, 64KB read, 5 staged files/20000 chars each/50000 total,
12 model rounds, 30 tool calls, 2000-char goal.

## Review Focus
Outside-root/symlink access; stale files; secret disclosure; missing evidence;
repeated application and partial multi-file failure must not claim success.
