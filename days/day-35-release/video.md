# Видео — день 35

Задача: «Автоматизирую подготовку релиза из настоящей Git-истории проекта».

1. Открыть http://127.0.0.1:8035 и нажать «Подготовить релиз».
2. Показать Release notes, риски и чеклист; затем Git evidence с коммитами и diff.
3. «Сохранить пакет» → «Скачать .md» → показать полученный Markdown.

Сказать: «DeepSeek анализирует реальные изменения и готовит пакет релиза.
Сервис проверяет ссылки на коммиты. Проверки и публикация остаются за человеком».
