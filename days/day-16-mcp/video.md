# Сценарий видео — День 16. Тридцать секунд

Показывается одно: **клиент подключается к MCP-серверу и получает список
инструментов.** Задание ровно про это, ничего усложнять не надо.

## Перед записью

```bash
cd ~/Documents/ai-challenge/days/day-16-mcp
```

Если хотите показать проверку на официальном сервере — поставьте его заранее,
установка в кадре не нужна:

```bash
python3 -m venv .venv && .venv/bin/python -m pip install mcp-server-time
```

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:04 | `python3 list_tools.py --raw` | сырой JSON-RPC: → initialize, ← ответ |
| 0:04–0:10 | — | `→ notifications/initialized  (уведомление — ответа не будет)` |
| 0:10–0:16 | — | `→ tools/list`, `← {"tools": [...]}` |
| 0:16–0:24 | — | **✓ соединение установлено**, список из 4 инструментов с параметрами |
| 0:24–0:30 | `python3 list_tools.py --server time` | тот же клиент на **официальном** сервере Anthropic |

## Что сказать

> «MCP поверх stdio — это JSON-RPC построчно. Вот рукопожатие: initialize,
> уведомление, запрос списка инструментов. Клиент написан на стандартной
> библиотеке, без SDK — двести семьдесят строк. Слева мой сервер над памятью
> агента, четыре инструмента. А чтобы это не выглядело как разговор с самим
> собой — тот же клиент на официальном сервере Anthropic: подключается,
> согласовывает протокол, отдаёт два инструмента.»

## Главный кадр

Две команды подряд, один и тот же клиент:

```
сервер: ai-advent-memory 1.0 · протокол 2025-06-18   ← свой
сервер: mcp-time 1.30.0 · протокол 2025-06-18        ← официальный Anthropic
```

Это и есть доказательство, что протокол настоящий, а не придуманный.

## Если спросят «а сервер надо арендовать?»

Нет. MCP-сервер поверх stdio — обычный процесс на этой же машине, клиент
запускает его как дочерний и говорит через stdin/stdout. Ни сети, ни хостинга.

## Версия на минуту

Добавить:

**1. Вызов инструмента** — `python3 list_tools.py --call`, видно результат.

**2. Свой сервер отдаёт состояние из прошлых дней:**

```
task_state({"session": "импорт-1с"}) →
    этап: выполнение
    шаг: пишем парсер выгрузки
    отметки: plan_approved
```

> «Пятнадцать дней агент копил память и состояние задач. Теперь всё это
> доступно любому MCP-клиенту.»

**3. Грабли** — показать в коде: уведомление без `id` ответа не ждёт, иначе
клиент зависнет; в stdout сервера только протокол, логи в stderr.

## Ловушки

| Что | Что делать |
|---|---|
| `--server time` ругается, что не установлен | поставить в `.venv`, команда есть в подсказке и в README |
| Сервер «завис» при прямом запуске | так и должно быть: он ждёт JSON-RPC в stdin. Запускать его должен клиент |
| Список пустой | память пуста — поработайте в приложениях дней 11–15, тогда появятся диалоги |
| Ошибка «Сервер закрыл вывод» | сервер упал на старте, причина будет в stderr — клиент его печатает |
