# Сценарий видео — День 31. Тридцать секунд

Показывается одно: **на один вопрос ассистент идёт в git, на другой —
в документацию, и видно, куда именно.**

## Перед записью

```bash
cd ~/Documents/ai-challenge/days/day-31-assistant
python3 web.py
```

Открыть `http://127.0.0.1:8000`. **Из терминала, не из .app** — приложению
macOS не даёт читать рабочее дерево, и вопрос про незакоммиченное
не сработает.

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:05 | ведёшь по левой панели | ветка `main`, незакоммиченное, последние коммиты — живое состояние |
| 0:05–0:12 | щёлкаешь вопрос с оранжевой меткой **state** | ответ про ветку, под ним оранжевая плашка `git current_branch` |
| 0:12–0:20 | щёлкаешь вопрос с сиреневой меткой **docs** | ответ про MRR, под ним сиреневые плашки с файлами документации, git не звался |
| 0:20–0:26 | щёлкаешь вопрос **both** | обе плашки сразу |
| 0:26–0:30 | жмёшь **Прогнать 9 вопросов** | таблица, внизу 9/9 |

## Что сказать

> «Ассистент знает проект с двух сторон. Спрашиваю, в какой я ветке —
> идёт в git, вот оранжевая плашка с инструментом. Спрашиваю, какая
> стратегия нарезки победила — в документацию, git не трогает вовсе.
> И третий вопрос, где нужны оба источника: сначала смотрит файлы,
> потом объясняет по документам. Девять вопросов с заранее известным
> источником — девять из девяти.»

## Главный кадр

Два ответа подряд: под одним оранжевая плашка `git current_branch`,
под другим сиреневые `day-21-indexing/README.md`. Видно, что источник
выбран, а не угадан.

## Если добавляете 20 секунд

**Локальная модель справляется хуже.** Поставьте галочку «на локальной
модели» и прогоните снова:

```
облако        9/9, источник не тот — 0
qwen2.5:3b    6/9, источник не тот — 2
```

> «Маленькая модель умеет вызвать инструмент, но хуже умеет его
> не вызывать: на вопрос по документам полезла смотреть diff.»

**И честно про приложение:** собранный .app не видит рабочее дерево —
macOS не пускает его к Documents, а в зеркале репозитория файлов нет.
Сервер честно говорит «нет доступа», а не делает вид, что всё
закоммичено.
