# День 1 — Первый запрос к LLM через API

## Задание

Минимальный код, который:
- отправляет запрос в LLM через API
- получает ответ
- выводит его в консоль или простой интерфейс (CLI / Web)

**Формат сдачи:** видео + код.

## Что сделано

Клиент к **DeepSeek API** (OpenAI-совместимый REST) на чистой стандартной библиотеке Python —
без `requests`, без SDK, без Flask. Ставить нечего, запрос собирается руками, поэтому видно
из чего он состоит: `POST https://api.deepseek.com/chat/completions`, заголовок
`Authorization: Bearer <ключ>` и JSON-тело с массивом `messages`.

| Файл | Что делает |
|------|-----------|
| [llm.py](llm.py) | сам HTTP-запрос к API + разбор ответа и ошибок |
| [main.py](main.py) | CLI: печатает ответ в консоль |
| [web.py](web.py) | простой веб-интерфейс на `http.server` |

## Настройка

Файл `.env` в корне репозитория уже создан (в git он не попадает). Осталось вписать в него ключ
с https://platform.deepseek.com/api_keys:

```
DEEPSEEK_API_KEY=sk-...
```

Модель переключается там же: `deepseek-chat` (V3, быстрая) или `deepseek-reasoner` (R1, рассуждает).

## Запуск

CLI:

```bash
python3 main.py "Объясни в двух предложениях, что такое REST API"
python3 main.py                 # спросит вопрос интерактивно
```

Веб:

```bash
python3 web.py                  # http://127.0.0.1:8000
```

## Что показать на видео

1. Показать `.env.example` и сказать, что реальный ключ лежит в `.env` и в git не попадает
   (**сам ключ в кадр не выводить**).
2. Показать `llm.py` — где формируется URL, заголовок и тело запроса.
3. Запустить CLI с вопросом, показать ответ в консоли.
4. Запустить `web.py`, задать вопрос в браузере, показать ответ.
5. Опционально: показать обработку ошибки — стереть ключ в `.env` и получить внятное
   сообщение вместо трейсбека.
