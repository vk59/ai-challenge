# Сценарий видео — День 7. Тридцать секунд

Задание: агент сохраняет и восстанавливает контекст между запусками.
Показывается ровно это, одним дублем, в терминале.

## Перед записью (не снимается)

```bash
cd ~/Documents/ai-challenge && rm -rf memory/   # чистый архив
cd days/day-07-memory
```

Шрифт в терминале покрупнее, окно узкое — чтобы текст читался на телефоне.

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:04 | `python3 cli.py` | шапка, **`0 пар в архиве`** |
| 0:04–0:12 | пишешь `Меня зовут Иван, запомни` | ответ агента |
| 0:12–0:15 | **Ctrl+D** | `Диалог «default» сохранён: 1 пар` |
| 0:15–0:19 | `python3 cli.py` **(та же команда)** | рамка `┌─ продолжаем диалог` с прошлой репликой |
| 0:19–0:28 | пишешь `Как меня зовут?` | **`Иван`** |
| 0:28–0:30 | — | конец |

## Что сказать (если нужен голос)

> «Агент с памятью на диске. Говорю ему своё имя. Выхожу — процесса больше нет.
> Запускаю заново: история поднялась с диска. Спрашиваю — помнит.»

Если без голоса — хватит одной подписи в начале: **«контекст переживает перезапуск»**.

## Если не влезаешь в 30 секунд

- вырезать паузы ожидания ответа при монтаже — это самое длинное место;
- второй вопрос сократить до `Как меня зовут?` (не длиннее);
- первую реплику набрать заранее в буфер обмена и вставить.

## Ловушка

`--store json` и `--store sqlite` — **два разных архива**. Запустишь второй раз
с другим флагом — агент «не вспомнит», и это будет выглядеть как сломанное демо.
Во всём дубле не трогай флаги вообще: `python3 cli.py` оба раза.

## Если попросят версию подлиннее (2 минуты)

Добавить после основного дубля два куска:

**1. Где лежит** (20 с) — из корня репозитория:

```bash
sqlite3 memory/agent.db "SELECT role, substr(content,1,40) FROM turns;"
```

> «Обычная таблица, вот те самые реплики.»

**2. Окно контекста ≠ архив** (60 с) — главное, что неочевидно в задании:

```bash
python3 cli.py --session окно --memory 2
```

Четыре вопроса подряд:

```
Запомни кодовое слово: барракуда.
Назови три любых цвета.
Сколько будет 17 умножить на 3?
Какое кодовое слово я просил запомнить?     ← не помнит
```

```
/история
```

> «Слово на диске есть, помечено «вне окна». На диск пишется весь разговор,
> в модель уезжают последние N пар. Грузить в модель весь архив нельзя: счёт
> за токены растёт с каждой репликой, а потом запрос упрётся в потолок контекста.»
