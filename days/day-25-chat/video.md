# Сценарий видео — День 25. Тридцать секунд

Показывается одно: **уточнение «а почему?» раскрывается в полноценный
запрос, источники приходят под каждым ответом, цель держится справа.**

## Перед записью

```bash
cd ~/Documents/ai-challenge/days/day-25-chat
./build_app.sh && open "dist/День 25.app"
```

**Если приложение уже открыто — сначала ⌘Q.** Нажмите `+` слева, чтобы
начать с чистого чата.

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:06 | пишешь «Как устроено сжатие истории диалога?» | ответ, под ним источники с chunk_id, справа появилась цель |
| 0:06–0:12 | пишешь «Сколько именно?» | над ответом серая строка «искал: сколько стоит сжатие истории диалога в токенах» |
| 0:12–0:18 | пишешь «Что с этим делать?» | снова раскрыто, снова источники |
| 0:18–0:24 | **ведёшь пальцем по панели справа** | цель диалога не менялась, ниже «что уточнил» и «зафиксировано» |
| 0:24–0:30 | пишешь «А с чего я начинал?» | ассистент отвечает по памяти задачи |

## Что сказать

> «Спрашиваю про сжатие истории — ответ со ссылками на файлы. Теперь
> уточняю: «сколько именно?». Такую реплику в индексе искать нечего,
> поэтому она сначала раскрывается по истории и цели — вот что ушло
> в поиск. И ещё раз: «что с этим делать?» — тоже раскрыто, тоже
> с источниками. Справа — память задачи: цель за весь разговор
> не менялась, под ней то, что я уточнил и что зафиксировано.»

## Главный кадр

Серая строка «искал: …» над ответом рядом с коротким вопросом «Сколько
именно?» — видно, во что превратилась реплика перед поиском.

## Если добавляете 20 секунд

**Прогон сценария.** Нажмите справа «1. Разбор расходов на токены»:

```
реплик                           12
источники у уверенных ответов   6/6
цель не потеряна              10/10
уточнений раскрыто               11
пустых ответов модели             0
```

> «Двенадцать реплик с ловушками: уточнения, отвлечение в сторону,
> вопрос не по теме. Цель не потерялась ни разу, источники пришли везде,
> где ответ был уверенным.»

**Что было без раскрытия.** В терминале:

```bash
python3 run.py 1 --no-rewrite
```

> «Без раскрытия уточнений близость падает ниже порога, и ассистент
> отказывается отвечать на свою же тему.»

## Ловушки

| Что | Что делать |
|---|---|
| Справа пусто | память задачи заполнится после первой реплики |
| «Индекс пуст» | `cd ../day-21-indexing && python3 build.py`, потом пересобрать приложение |
| Ответ «не знаю» на обычный вопрос | индекс отстал от документов, пересоберите |
| Цель сменилась не вовремя | бывает, если вопрос уводит далеко в сторону; продолжите по теме, цель вернётся |
| Прогон сценария долгий | 12–13 реплик по три запроса каждая, несколько минут |
