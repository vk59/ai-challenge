# День 18 — Планировщик и фоновые задачи

## Задание

MCP-инструмент с отложенным или периодическим выполнением. Сохранять данные,
выполняться по расписанию, возвращать агрегированный результат. Агент,
который работает 24/7 и периодически выдаёт сводку.

## Честно про «24/7»

Фоновый поток внутри приложения живёт ровно столько, сколько открыто окно.
Назвать это круглосуточной работой было бы враньём, поэтому здесь три уровня,
и разница между ними проговаривается прямо:

| уровень | когда работает | что даёт |
|---|---|---|
| поток в процессе | пока открыто приложение | задачи идут по расписанию |
| **наверстывание** | при каждом запуске | досчитывает пропущенное за время простоя |
| **launchd-агент** | всегда, даже после перезагрузки | настоящий круглосуточный фон |

Третий уровень ставится отдельной командой — он не нужен для демонстрации,
но без него «24/7» остаётся словом:

```bash
./install_agent.sh          # опрос каждые 5 минут, приложение не нужно
./install_agent.sh --remove # снять
```

### Наверстывание: одна из немногих неочевидных вещей

Ноутбук был закрыт три дня, задача ежечасная. Выполнить её семьдесят два
раза подряд — бессмысленно и дорого. Она выполняется **один раз** и честно
сообщает, сколько периодов пропущено:

```
✓ За 7 дн.: 9 коммитов в 2 дней  (пропущено периодов: 72)
```

Для сводок это правильно: нужна свежая сводка, а не семьдесят две старых.

## Что умеют задачи

| тип | что делает | настраивается |
|---|---|---|
| `repo_digest` | сводка по репозиторию: коммиты за период | за сколько дней |
| `token_report` | расход токенов и денег по диалогам | — |
| `reminder` | напоминание с текстом | текст |

Каждая задача: название, частота, включена или нет. Всё это правится
в окне и переживает перезапуск — задачи и прогоны лежат в SQLite.

## Настройка в окне

Правая панель — главное в этом дне:

- **список задач**: тип, частота, когда следующий запуск, сколько прогонов
- **переключатель** — выключить, не удаляя
- **Выполнить** — прогнать сейчас, не дожидаясь срока
- **Сводка** — агрегированный результат: сколько прогонов, сколько удачных,
  сколько периодов пропущено, что в последних сводках
- **Настроить** — поменять название, частоту, параметры
- **Новая задача** — выбрать тип, задать частоту, при необходимости
  запустить сразу

Сроки в панели обновляются сами: окно раз в пять секунд подтягивает
состояние, иначе «через 59 с» висело бы вечно.

## Агент управляет теми же задачами словами

Семь инструментов MCP: `list_tasks`, `add_task`, `run_task_now`,
`task_digest`, `update_task`, `delete_task`, `toggle_task`.

```
вы › Какие фоновые задачи запланированы?
🔧 sched__list_tasks({})
→ «Запланированы 2 задачи: Размяться (reminder, каждые 5 мин),
   Сводка (repo_digest, каждый час)…»
```

Окно и агент работают с одной базой: завели задачу руками — агент её видит,
и наоборот.

## Кто крутит фон

Фоновый поток живёт **только в MCP-сервере**. Окно управляет теми же
данными, но своего потока не поднимает — иначе две копии планировщика
выполняли бы одну задачу по два раза.

Исполнители задач импортируются в окно из самого сервера, а не копируются:
одна реализация на оба пути, и «Выполнить сейчас» делает ровно то же,
что фон.

## Мелочи, которые видно только в работе

**Упавшая задача не роняет планировщик.** Она записывает неудачный прогон
и ждёт следующего срока — в сводке это видно как `неудачных 1`.

**История прогонов подрезается** до последних пятидесяти на задачу. Без
потолка таблица росла бы вечно, а для сводки нужны последние.

**Смена интервала сдвигает срок от текущего момента.** Поменяли «каждый час»
на «каждые пять минут» — следующий запуск через пять минут, а не в старое
время.

**Интервалы пишутся по-человечески.** «Каждые 60 с» формально верно, но
человек говорит «каждую минуту» — и в панели это видно постоянно.

## Запуск

```bash
cd days/day-18-scheduler

python3 web.py                        # окно: http://127.0.0.1:8000
./build_app.sh && open "dist/День 18.app"
python3 runner.py --list              # задачи в терминале
python3 runner.py                     # выполнить всё, чему вышел срок
./install_agent.sh                    # круглосуточный фон
```
