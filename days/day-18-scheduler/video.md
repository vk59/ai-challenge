# Сценарий видео — День 18. Тридцать секунд

Показывается одно: **задача заводится, настраивается и выполняется сама
по расписанию.**

## Перед записью

```bash
cd ~/Documents/ai-challenge/days/day-18-scheduler
./build_app.sh && open "dist/День 18.app"
```

**Если приложение уже открыто — сначала ⌘Q.** `open` не перезапускает
работающее приложение, покажете старую сборку.

Заведите заранее одну задачу с интервалом в минуту, чтобы к началу записи
у неё уже был хотя бы один прогон — иначе панель будет пустой.

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:05 | ведёшь по правой панели | список задач: тип, частота, «через 34 с», число прогонов |
| 0:05–0:12 | раскрываешь «Новая задача», выбираешь `reminder`, ставишь 1 минуту | форма настройки |
| 0:12–0:16 | **Завести** | задача появилась в списке, отсчёт пошёл |
| 0:16–0:22 | жмёшь **Выполнить** у любой задачи | всплывает результат, счётчик прогонов растёт |
| 0:22–0:30 | жмёшь **Сводка** | «прогонов 4: удачных 4», последние сводки с временем |

## Что сказать

> «Фоновые задачи по расписанию. Тип, частота, параметры — всё настраивается
> здесь. Завожу напоминание раз в минуту — пошёл отсчёт до следующего запуска.
> Могу не ждать и выполнить сейчас. А вот накопленный результат: сколько
> прогонов было, сколько удачных, что они возвращали. Всё это лежит в SQLite
> и переживает перезапуск.»

## Главный кадр

Панель со сводкой: видно, что задача выполнялась **несколько раз сама**, —
это и отличает планировщик от кнопки «сделать сейчас».

## Если добавляете 20 секунд

**1. Агент управляет теми же задачами словами:**

```
вы › Какие фоновые задачи запланированы?
🔧 sched__list_tasks({})
```

> «Окно и агент работают с одной базой: завёл руками — агент видит.»

**2. Честность про 24/7:**

> «Пока окно открыто, задачи идут потоком внутри приложения. Закрыл — фон
> встал, но при следующем запуске сработает наверстывание. А настоящий
> круглосуточный фон — это launchd-агент, ставится одной командой.»

Можно показать в терминале:

```bash
./install_agent.sh
launchctl list | grep aiadvent
tail -3 ~/Library/Application\ Support/AI\ Advent/scheduler.log
```

## Ловушки

| Что | Что делать |
|---|---|
| Панель пустая | задач нет — заведите через «Новая задача» |
| «через 59 с» не меняется | окно подтягивает состояние раз в 5 секунд, подождите |
| Задача не выполнилась сама | проверьте, что она включена (переключатель слева) |
| Хотите чистый старт | удалите `~/Library/Application Support/AI Advent/scheduler.db` |
