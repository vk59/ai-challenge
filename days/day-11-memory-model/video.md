# Сценарий видео — День 11. Тридцать секунд

Показывается одно: **долговременная память переживает смену диалога,
а рабочая — нет.**

## Перед записью

```bash
cd ~/Documents/ai-challenge/days/day-11-memory-model
./build_app.sh && open "dist/День 11.app"
```

Собрать заранее. Память приложения живёт в `~/Library/Application Support/AI Advent/memory`
— если нужен чистый старт, удалить `agent.db` оттуда.

Окно пошире: справа три панели, их должно быть видно.

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:04 | окно открыто | три пустые панели: краткосрочная, рабочая, долговременная |
| 0:04–0:14 | пишешь реплику (ниже) | панели заполняются, записи подсвечиваются |
| 0:14–0:20 | — | под ответом: **`рабочая: +5 · долговременная: +3`** |
| 0:20–0:25 | жмёшь **«Новый диалог»** | две верхние панели очищаются, **нижняя остаётся** |
| 0:25–0:30 | спрашиваешь «как меня зовут и какой бюджет?» | помнит имя, про бюджет — нет |

## Реплика для ввода

```
Меня зовут Иван, пишу на Python. Бюджет проекта 800 тысяч, срок 3 месяца. Решили брать PostgreSQL 16.
```

## Что сказать

> «Три слоя памяти. Краткосрочная — реплики диалога. Рабочая — данные задачи:
> бюджет, срок. Долговременная — профиль и решения: имя, язык, выбор базы.
> Нажимаю «Новый диалог»: краткосрочная и рабочая очистились, долговременная
> осталась. Спрашиваю — имя помнит, а бюджет нет, потому что бюджет был
> данными той задачи, а имя это про меня.»

Если без голоса — подпись в момент нажатия кнопки: **«диалог новый, а человек
тот же»**.

## Главный кадр

Момент после «Нового диалога»: две панели пустые, третья полная. Задержись
на нём — это вся суть дня в одном экране.

## Версия на минуту

Добавить ручное управление — оно показывает «явный выбор, что куда»:

- вписать в поле долговременной `любимый редактор` / `Vim`, выбрать «профиль», `+`
- нажать крестик на любой записи — забыть навсегда
- показать статусную строку: **служебных** токенов столько-то — раскладка стоит
  отдельного запроса на каждую реплику

И терминал, если нужно показать код:

```bash
python3 cli.py
/слои
```

## Ловушки

| Что | Что делать |
|---|---|
| Панели не заполнились | раскладка идёт отдельным запросом, занимает пару секунд после ответа |
| В рабочей появился мусор вроде «статус: ждём уточнения» | так бывает, модель придумывает служебные поля — сказать честно, это в README |
| Долговременная не пуста на старте | память переживает перезапуск, удалить `agent.db` для чистого старта |
| «Новый диалог» очистил всё | значит смотрите не на ту панель — долговременная нижняя |
