# Сценарий видео — День 11. Тридцать секунд

Показывается одно: **долговременная память переезжает в новый диалог,
а рабочая остаётся в старом.**

## Перед записью

```bash
cd ~/Documents/ai-challenge/days/day-11-memory-model
./build_app.sh && open "dist/День 11.app"
```

Собрать заранее. Память приложения лежит в
`~/Library/Application Support/AI Advent/memory/agent.db` — для чистого старта
удалить её оттуда.

Окно пошире: справа три панели, их должно быть видно.

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:04 | окно открыто | три пустые панели: краткосрочная, рабочая, долговременная |
| 0:04–0:13 | вводишь реплику (ниже) | панели заполняются, записи подсвечиваются |
| 0:13–0:17 | — | под ответом **`рабочая: +4 · долговременная: +3`** |
| 0:17–0:22 | жмёшь **«Новый диалог»** | две верхние панели пустеют, **нижняя остаётся** |
| 0:22–0:27 | «как меня зовут и какой бюджет?» | помнит имя, про бюджет — нет |
| 0:27–0:30 | в списке вверху выбираешь прежний диалог | бюджет вернулся на место |

## Реплика для ввода

```
Меня зовут Иван, пишу на Python. Бюджет проекта 800 тысяч, срок 3 месяца. Решили брать PostgreSQL 16.
```

## Что сказать

> «Три слоя. Краткосрочная — реплики. Рабочая — данные задачи: бюджет, срок.
> Долговременная — профиль и решения: имя, язык, выбор базы. Создаю новый
> диалог: первые два слоя пустые, третий переехал. Спрашиваю — имя помнит,
> бюджет нет, потому что бюджет был данными той задачи. Возвращаюсь в старый
> диалог — бюджет на месте, он никуда не делся.»

Если без голоса — подпись в момент переключения: **«диалог новый, а человек
тот же»**.

## Два главных кадра

1. **Сразу после «Нового диалога»**: две панели пустые, третья полная.
2. **Возврат в старый диалог через список**: рабочая панель снова полная.

Второй кадр важнее, чем кажется: он доказывает, что старый диалог не стёрт,
а просто отложен. Без него легко подумать, что кнопка всё удаляет.

## Не перепутай кнопки

| кнопка | что делает |
|---|---|
| **Новый диалог** | создаёт новую сессию, старая цела |
| **Стереть** | стирает текущую сессию насовсем |

Для сценария нужна первая. Вторую показывать не обязательно.

## Версия на минуту

Добавить ручное управление — оно показывает «явный выбор, что куда»:

- вписать в поле долговременной `любимый редактор` / `Vim`, выбрать «профиль», `+`
- нажать крестик на записи — забыть навсегда
- показать в статусной строке цифру **служебных** токенов: раскладка стоит
  отдельного запроса на каждую реплику

И терминал, если нужно показать код:

```bash
python3 cli.py
/слои
```

## Ловушки

| Что | Что делать |
|---|---|
| Панели не заполнились сразу | раскладка идёт отдельным запросом после ответа, пара секунд |
| В памяти появился мусор («статус», «не указано») | роутер иногда сочиняет; удалить крестиком, в README это описано |
| Долговременная не пуста на старте | она переживает перезапуск — удалить `agent.db` для чистого старта |
| Нажал «Стереть» вместо «Новый диалог» | старый диалог стёрт насовсем, начинать дубль заново |
