# Сценарий видео — День 26. Тридцать секунд

Показывается одно: **знакомый чат с источниками работает целиком на этой
машине, без сети и без ключей.**

## Перед записью

```bash
brew install ollama
ollama serve &
ollama pull qwen2.5:3b

cd ~/Documents/ai-challenge/days/day-26-local-llm
./build_app.sh && open "dist/День 26.app"
```

**Если приложение уже открыто — сначала ⌘Q.** `open` переиспользует
работающее, покажете старую сборку.

Слева в панели «Ollama» должно быть зелёное «запущен».

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:05 | ведёшь по левой панели | «Ollama запущен», две модели: `qwen2.5:3b` 1.9 ГБ и `qwen2.5:7b` 4.7 ГБ |
| 0:05–0:10 | пишешь в чат «Какая стратегия нарезки победила в сравнении?» | ответ, под ним источник с chunk_id, строка «qwen2.5:3b · … ток. · …с» |
| 0:10–0:18 | пишешь «А на сколько именно?» | серая строка «искал: на сколько именно стратегия по структуре превосходит…», потом ответ 0.325 |
| 0:18–0:24 | переключаешься на вкладку **Стенд с замерами**, жмёшь «6 запросов» | таблица: галочки, секунды, токены в секунду |
| 0:24–0:30 | ставишь галочку «в облаке», жмёшь ещё раз | у облака 6/6, у локальной 4/6 — но локальная вдвое быстрее по токенам |

## Что сказать

> «Модель работает на этом ноутбуке: Ollama, Qwen два гигабайта. Это тот
> же чат, что был вчера — с историей, с раскрытием уточнений, с источниками
> под ответом. Только без сети и без ключей. Спрашиваю, уточняю «а на
> сколько именно» — уточнение раскрылось и нашло ответ. Теперь стенд:
> шесть запросов от простого к сложному. Локальная проходит четыре из
> шести и выдаёт токены вдвое быстрее облака. Облако проходит все шесть.
> Вот и весь размен.»

## Главный кадр

Ответ в чате с источником `days/day-21-indexing/README.md#structural#5`
и подписью `qwen2.5:3b` — видно, что отвечала локальная модель, и видно,
откуда она это взяла.

## Если добавляете 20 секунд

**Незнание лечится документами.** Кнопка «Дать свои документы»:

```
без документов   0/3
с документами    3/3
```

> «Без документов маленькая модель уверенно говорит, что MRR — это
> Monthly Recurring Revenue. С нашими документами отвечает правильно
> и со ссылкой. Она не знает фактов, но умеет читать.»

**Холодный старт.** В терминале:

```bash
python3 probe.py --cold
```

> «Загрузка двух гигабайт в память — шесть десятых секунды. Дальше
> каждый ответ за сотые.»

## Ловушки

| Что | Что делать |
|---|---|
| Слева «не отвечает» | `ollama serve` в терминале |
| «моделей нет» | `ollama pull qwen2.5:3b` |
| Ответ «не упоминается» на хороший вопрос | переформулируйте точнее: у поиска промах по полноте, не у модели |
| Цитаты красные «выдумка» | так и есть: маленькие модели пересказывают вместо копирования, об этом в README |
| Ответ идёт 10 секунд | включён реранкинг, это ещё один запрос к модели |
| Смена модели очистила чат | так задумано: иначе половина истории от одной модели, половина от другой |
