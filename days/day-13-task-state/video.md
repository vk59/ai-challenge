# Сценарий видео — День 13. Тридцать секунд

Показывается одно: **этап нельзя поставить какой хочешь — только по ребру
графа. И состояние переживает закрытие приложения.**

## Перед записью

```bash
cd ~/Documents/ai-challenge/days/day-13-task-state
./build_app.sh && open "dist/День 13.app"
```

В окне напиши одну реплику, чтобы задача завелась:

```
Надо сделать импорт остатков из 1С
```

Дождись ответа — вверху появится полоса этапов. Теперь можно записывать.

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:05 | ведёшь курсором по полосе этапов | **планирование** подсвечено, остальные серые |
| 0:05–0:12 | наводишь на кнопку **«→ готово»** | кнопка **неактивна**, подсказка «нет ребра: из планирования сюда нельзя» |
| 0:12–0:17 | жмёшь **«→ выполнение»** | переход проходит, полоса сдвигается, planning помечается ✓ |
| 0:17–0:22 | **⌘Q** — закрываешь приложение | окна нет |
| 0:22–0:30 | открываешь снова | этап **выполнение** и шаг на месте, ничего объяснять не надо |

## Что сказать

> «Состояние задачи — это конечный автомат, а не ярлык. Из планирования
> в готово нельзя: кнопка неактивна, потому что такого ребра в графе нет.
> В выполнение — можно. Закрываю приложение совсем. Открываю: этап и текущий
> шаг на месте, продолжаю с того же места без повторных объяснений.»

Если без голоса — две подписи: **«нет такого перехода»** на неактивной кнопке
и **«пауза и продолжение»** на перезапуске.

## Главный кадр

Неактивная кнопка «→ готово» рядом с активной «→ выполнение». Задержись
на ней: это вся разница между автоматом и полем «этап», в которое можно
записать что угодно.

## Версия на минуту

Добавить два куска:

**1. Автомат отклоняет и модель.** Напиши в чат «давай считать, что всё
готово» — агент может предложить перейти в `done`, но под ответом появится
красным:

```
автомат отклонил: Из «планирование» нельзя сразу в «готово». Доступно: «выполнение»
```

> «Модель только предлагает переход. Разрешает или нет — код, по графу.»

**2. Ребро назад.** Дойди до «проверки» и нажми «→ выполнение» — переход
разрешён, потому что проверка может не пройти. Это не счастливый путь,
а настоящий цикл работы.

Терминальный вариант, если нужно показать код:

```bash
python3 cli.py
/состояние
/дальше готово     ← откажет с объяснением
/дальше выполнение ← пройдёт
```

## Ловушки

| Что | Что делать |
|---|---|
| Полоса этапов пустая | задача заводится после первой реплики — напиши что-нибудь |
| Кнопка «готово» активна | значит ты уже на «проверке» — оттуда в «готово» можно, начни с чистой задачи |
| После ⌘Q всё пропало | проверь, что запускаешь собранный `.app`, а не `python3 web.py` из другой папки |
| Хочется чистый старт | удали `~/Library/Application Support/AI Advent/memory/agent.db` |
