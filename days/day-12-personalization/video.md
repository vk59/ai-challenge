# Сценарий видео — День 12. Тридцать секунд

Показывается одно: **один вопрос, разные профили — разные ответы.**

## Перед записью

```bash
cd ~/Documents/ai-challenge/days/day-12-personalization
./build_app.sh && open "dist/День 12.app"
```

Собрать заранее. Профили (новичок, senior, аудитор) создаются сами при первом
запуске — ничего настраивать не надо.

Окно пошире: колонки сравнения должны поместиться хотя бы три.

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:05 | окно открыто, печатаешь вопрос | справа панель профиля, слева чаты |
| 0:05–0:08 | жмёшь **«Сравнить профили»** | открывается панель с колонками |
| 0:08–0:22 | *(ускорить ×4)* | ответы стримятся в колонки параллельно |
| 0:22–0:30 | ведёшь курсором по колонкам | внизу каждой: знаков, токенов, код да/нет |

## Вопрос для ввода

```
Как хранить пароли пользователей?
```

## Что сказать

> «Один вопрос — четыре профиля. Без профиля — две с половиной тысячи знаков.
> Senior: сухо, без азов — вдвое короче. Аудитор: у него в профиле прямой
> запрет на примеры кода — единственный ответ без единого блока кода.
> Новичок — пошагово и подробно. Вопрос при этом один и тот же, я не сказал
> ни слова о форме ответа.»

Если без голоса — подпись поверх панели: **«вопрос один, профили разные»**.

## Главный кадр

Момент, когда видно нижние строки всех колонок разом:

```
без профиля   2547 знаков · код: да
senior        1227 знаков · код: да
аудитор       1757 знаков · код: нет
новичок       2087 знаков · код: да
```

Строка аудитора — самая убедительная: ограничение из профиля выполнено буквально.

## Версия на минуту

Добавить создание профиля на лету:

- в правой панели раскрыть «создать профиль»
- вписать имя `краткий`, тон `односложно`, ограничения `максимум два предложения`
- «Сохранить и включить»
- задать обычный вопрос в чат — ответ станет коротким без всяких «Сравнить»

И показать цену персонализации: в статусной строке внизу **«из них профиль»** —
профиль уезжает в каждый запрос и стоит 60–80 токенов.

## Ловушки

| Что | Что делать |
|---|---|
| «Сравнить профили» ругается | вопрос берётся из поля ввода — сначала напечатай его |
| Сравнение идёт долго | это 4 запроса подряд, минута-полторы. Ускорять при монтаже |
| Колонок больше трёх, не влезают | панель прокручивается вбок, или сузь окно памяти |
| Ответы почти одинаковые | профили слишком похожи — у senior и аудитора должны быть **прямые** ограничения |
| Сравнение попало в чат | не должно: оно идёт в служебной сессии. Если попало — баг, скажи |
