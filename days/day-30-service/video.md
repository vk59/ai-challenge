# Сценарий видео — День 30. Тридцать секунд

Показывается одно: **свой ИИ отвечает с телефона, а запросы не выходят
из квартиры.**

## Перед записью

```bash
cd ~/Documents/ai-challenge/days/day-30-service
./install_service.sh --lan
```

Запишите адрес и ключ из вывода. Откройте на телефоне
`http://192.168.1.122:8080/chat`, вставьте ключ в «Настройки» заранее —
в кадре этого делать не надо.

Снимать лучше телефон в руке, а экран ноутбука — вторым планом.

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:05 | показываешь телефон с открытым чатом | зелёная точка, сверху `qwen2.5:3b · 192.168.1.122:8080` |
| 0:05–0:14 | пишешь с телефона вопрос, ждёшь ответ | ответ приходит, под ним «2.1с · 180 ток. · 3/30 за минуту» |
| 0:14–0:20 | **выключаешь Wi-Fi на ноутбуке? нет — показываешь терминал** | `curl` без ключа → `401 unauthorized` |
| 0:20–0:26 | запускаешь `python3 loadtest.py` | три галочки: доступ, устойчивость, ограничения |
| 0:26–0:30 | показываешь строку про лимит | «лимит сработал на 17-м запросе, Retry-After: 47с» |

## Что сказать

> «Модель работает на ноутбуке дома, а это телефон в той же сети.
> Спрашиваю — отвечает за две секунды, и видно, сколько запросов
> осталось в минуту. Без ключа сервис не отвечает вовсе: четыреста
> первый. Проверка нагрузкой: шесть клиентов разом, все получили ответ,
> очередь доходила до пяти — модель одна, параллелить нечего. Лимит
> частоты срабатывает и говорит, через сколько повторить. Ни один
> запрос не вышел в интернет.»

## Главный кадр

Телефон с ответом и строкой «2.1с · 180 ток. · 3/30 за минуту» — видно,
что это свой сервис, а не чужое приложение.

## Если добавляете 20 секунд

**Собственный клиент через сервис:**

```bash
python3 -c "
import sys; sys.path.insert(0,'../../shared')
from llm import Provider, ask
S = Provider('Home','http://192.168.1.122:8080/v1','AI_ADVENT_SERVICE_KEY','')
print(ask('Скажи ровно: через свой сервис', provider=S).text)"
```

> «Эндпоинт OpenAI-совместимый, поэтому весь код прошлых дней работает
> через этот сервис без правок — меняется только адрес.»

**И честно про грабли:** служба из launchd не видит `~/Documents` —
та же защита macOS, что ломала приложение в семнадцатый день. И подхватила
питон из Xcode версии 3.9. Обе починены в установщике.

## Ловушки

| Что | Что делать |
|---|---|
| Телефон не открывает адрес | должен быть в той же сети Wi-Fi, не в гостевой |
| «сервис недоступен» в шапке | `launchctl list \| grep aiadvent`, потом лог в Application Support |
| 401 на всё | ключ из вывода установщика, не из репозитория — они разные |
| Ответ идёт 6 секунд | значит впереди очередь, это нормально при нескольких клиентах |
| Хочется снять с автозапуска | `./install_service.sh --remove` |
