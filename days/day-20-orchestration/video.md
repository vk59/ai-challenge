# Сценарий видео — День 20. Тридцать секунд

Показывается одно: **один запрос — вызовы уходят на три разных сервера,
и порядок правильный.**

## Перед записью

```bash
cd ~/Documents/ai-challenge/days/day-20-orchestration
./build_app.sh && open "dist/День 20.app"
```

**Если приложение уже открыто — сначала ⌘Q.** `open` не перезапускает
работающее приложение, покажете старую сборку.

Ничего заранее нажимать не надо: сценарии уже кнопками наверху.

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:05 | ведёшь по трём плашкам вверху | `git` оранжевый, `sched` синий, `pipe` зелёный — 19 инструментов |
| 0:05–0:08 | жмёшь кнопку **5. длинный флоу через три сервера** | запрос ушёл |
| 0:08–0:20 | ждёшь | в переписке появляются вызовы, каждый своего цвета; справа растёт «Маршрут» |
| 0:20–0:26 | **ведёшь пальцем по панели «Маршрут» сверху вниз** | 1 git → 2 pipe → 3 pipe → 4 pipe → 5 sched, цвет меняется |
| 0:26–0:30 | показываешь галочки под маршрутом | ✓ серверы: git, pipe, sched · ✓ порядок: search → summarize → save_to_file |

## Что сказать

> «Три MCP-сервера подключены разом: факты о репозитории, планировщик и
> конвейер. Девятнадцать инструментов в одном списке, кнопок «вызвать» нет —
> выбирает агент. Один запрос из трёх частей. Смотрите на маршрут справа:
> первый вызов ушёл в git, следующие три — в конвейер, последний — в
> планировщик. Цвет меняется — значит сменился сервер. И снизу машинная
> проверка: задействованы все три, порядок цепочки не нарушен.»

## Главный кадр

Панель «Маршрут» целиком: пять пронумерованных вызовов, где видно **смену
цвета** — оранжевый, зелёный, зелёный, зелёный, синий. Это и есть
оркестрация в одном кадре.

## Если добавляете 20 секунд

**Ловушка маршрутизации.** Нажмите сценарий **3. похожие инструменты
на разных серверах**:

```
Найди коммиты, в сообщении которых упоминается MCP.
```

В маршруте один вызов — `git__search_commits`.

> «Искать умеют два сервера: git и конвейер. Здесь спросили факт — агент
> взял git и не полез в конвейер. Это проверяется правилом forbid:
> `pipe__search` в этом сценарии запрещён.»

**Проверка в терминале:**

```bash
python3 flow.py
```

> «Пять сценариев, у каждого ожидание по серверам, вызовам и порядку.
> Пять из пяти.»

## Ловушки

| Что | Что делать |
|---|---|
| Плашек серверов нет | сервер не поднялся — закройте и откройте приложение |
| Маршрут не растёт | агент отвечает без инструментов, переформулируйте конкретнее |
| Долго думает на шаге «сжимаю» | это запрос к модели, 3–5 секунд |
| Маршрут от прошлого запроса | он очищается сам при новом; кнопка «очистить» в шапке панели |
| Порядок вызовов другой, чем у меня | нормально: независимые части могут перемешаться, проверка следит только за зависимой цепочкой |
