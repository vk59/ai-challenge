# Сценарий видео — День 29. Тридцать секунд

Показывается одно: **трёхмиллиардная модель после настройки догнала
семимиллиардную и стала втрое быстрее.**

## Перед записью

```bash
cd ~/Documents/ai-challenge/days/day-29-tuning
./build_app.sh && open "dist/День 29.app"
```

**Если приложение уже открыто — сначала ⌘Q.**

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:05 | ведёшь по левой панели | цель: догнать 7B; ниже список вариантов — температура, квантование, указание строк |
| 0:05–0:08 | щёлкаешь **вопрос 6** | три колонки заполняются |
| 0:08–0:18 | **ведёшь пальцем по строке «дословно»** | было 0%, стало 100%, у 7B 100% — и секунды: 2.35 → 0.92 → 2.53 |
| 0:18–0:24 | жмёшь **Показать прогон** | таблица восьми вариантов, зелёным подсвечен победитель |
| 0:24–0:30 | показываешь полосы внизу | опора, дословность, медиана |

## Что сказать

> «В прошлый раз у трёхмиллиардной модели восемьдесят семь процентов
> цитат были выдуманы. Задача — догнать семимиллиардную и не потерять
> в скорости. Вот один вопрос: было ноль процентов дословных цитат,
> стало сто, у большой модели тоже сто — но она втрое медленнее.
> Таблица приёмов: температура не дала ничего, квантование сделало
> только хуже и медленнее. Сработало одно — перестать просить модель
> переписывать текст. Пронумеровал строки, модель возвращает номера,
> текст подставляю я. Выдумать цитату стало физически нечем.»

## Главный кадр

Три колонки, строка «дословно»: **0% → 100% → 100%**, и под ними
секунды **2.35 → 0.92 → 2.53**.

## Если добавляете 20 секунд

**Отрицательный результат про квантование:**

```
base (4 бита)   14/20 верных, 2.27с
q8  (8 бит)     16/20 верных, 3.75с
```

> «Восемь бит вместо четырёх: плюс два верных ответа — это шум, —
> и вдвое медленнее. Больше бит на этой задаче не купили ничего.»

**И честная оговорка:** тот же приём на семимиллиардной модели сделал
хуже, опора упала с 8 до 4. Это настройка под маленькую модель,
а не улучшение вообще.

## Ловушки

| Что | Что делать |
|---|---|
| «Показать прогон» пусто | нет `tune-все.json`, нажмите «Прогнать заново» |
| «Прогнать заново» долго | 10 вопросов × 10 вариантов; для показа хватит «1 повтор» |
| Секунды не как в README | разброс большой, зависит от загрузки памяти — об этом в README |
| Вариант q8 или q5 падает | модель не скачана: `ollama pull qwen2.5:3b-instruct-q8_0` |
