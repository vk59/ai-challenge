# День 2 — Формат ответа

## Задание

Отправить один и тот же запрос, но:
- добавить явное описание формата ответа
- добавить ограничение на длину ответа
- добавить условие завершения (stop sequence или явную инструкцию)

Сравнить ответы без ограничений и с ограничениями.

**Формат сдачи:** видео + код.

## Главная мысль

Ответ модели ограничивается в двух разных местах, и это принципиально разные вещи:

|  | Где живёт | Что это | Гарантия |
|--|-----------|---------|----------|
| **Промпт** | текст в `system` | просьба человеческим языком | модель *старается* выполнить |
| **Параметр** | поле в JSON-теле запроса | правило на стороне API | выполняется *всегда* |

Промпт — «отвечай не длиннее 30 слов». Параметр — `max_tokens: 60`, после которого генерация
обрывается, даже посреди слова. Первое даёт красивый короткий ответ, второе даёт
гарантированный потолок. В бою обычно нужны оба: промпт для качества, параметр для страховки.

Три рычага, добавленные ко дню 1:

- `max_tokens` — жёсткий потолок длины. Ответ обрывается, `finish_reason` становится `length`
- `stop` — список строк-триггеров. Модель дописала строку → генерация прекратилась,
  сама строка в ответ не попала
- `response_format: {"type": "json_object"}` — API гарантирует синтаксически валидный JSON

## Что сделано

Шесть прогонов одного вопроса «Что такое REST API?»: базовый, затем по одному рычагу,
затем всё вместе. Скрипт показывает каждый ответ и сводит результаты в таблицу.

| Файл | Что делает |
|------|-----------|
| [compare.py](compare.py) | шесть вариантов запроса и сравнение результатов |
| [../../shared/llm.py](../../shared/llm.py) | клиент к API с поддержкой `max_tokens`, `stop`, `response_format` |

Клиент переехал в `shared/`: со дня 2 он нужен всем заданиям, а копировать его по папкам
смысла нет. День 1 намеренно оставлен со своей копией — он уже сдан, и его код показан
на видео как есть.

## Результаты

Реальный прогон, `deepseek-chat`, вопрос «Что такое REST API?»:

| № | Вариант | Слов | Токенов | `finish_reason` |
|---|---------|-----:|--------:|-----------------|
| 1 | Без ограничений | 423 | 919 | `stop` |
| 2 | Формат: строгий JSON | 47 | 114 | `stop` |
| 3 | Длина: инструкцией | 23 | 42 | `stop` |
| 4 | Длина: параметром `max_tokens=60` | 27 | 60 | **`length`** |
| 5 | Условие завершения | 42 | 94 | `stop` |
| 6 | Всё вместе | 33 | 86 | `stop` |

Что тут интересного:

**Без ограничений модель разворачивается на всю катушку** — 919 токенов, заголовки, эмодзи,
таблица сравнения с SOAP и GraphQL. Ответ хороший, но в интерфейс такое не вставишь.

**Вариант 4 обрывается на полуслове:** «…Простыми слова». Это и есть `max_tokens` — API
досчитал до шестидесяти и выключил генерацию, не спросив модель. `finish_reason=length`
как раз и означает «ответ неполный». По нему в проде можно понять, что надо перезапросить.

**Вариант 3 короче варианта 4** (42 токена против 60), хотя жёсткого потолка там нет.
Инструкция сработала лучше обрезания: модель сама уместилась и закончила мысль.

**Стоп-последовательность не попадает в ответ.** Модель дописала `<<<КОНЕЦ>>>`, API увидел
совпадение и оборвал генерацию до него. В тексте маркера нет — удобно, когда нужен
разделитель, а не мусор в выводе.

**Всё вместе — в 10.7 раза короче базового** и при этом машиночитаемо.

## Запуск

Зависимостей нет, нужен только Python 3.10+ и ключ в `.env` (см. корневой README).

```bash
cd days/day-02-response-format
python3 compare.py                    # вопрос по умолчанию
python3 compare.py "Что такое HTTP?"  # свой вопрос
python3 compare.py --only 1,6         # только базовый и «всё вместе»
```

Один полный прогон — шесть запросов к API, примерно 1300 токенов.

## Что показать на видео

1. Показать [compare.py](compare.py) — список `VARIANTS`, там наглядно видно, что именно
   добавляется в каждом варианте.
2. Показать в [shared/llm.py](../../shared/llm.py) функцию `_build_request` — как
   `max_tokens`, `stop` и `response_format` попадают в JSON-тело запроса.
3. Запустить `python3 compare.py` и дождаться таблицы.
4. Отдельно остановиться на варианте 4 — оборванное слово и `finish_reason=length`.
5. Сравнить первый и последний ответ: 919 токенов против 86 при том же вопросе.
