# Сценарий видео — День 8. Тридцать секунд

Задание требует показать два сюжета: **как растёт счёт** и **что ломается
при переполнении**. Оба за 30 секунд — только если не ждать ответы вживую.

## Перед записью (не снимается)

```bash
cd ~/Documents/ai-challenge/days/day-08-tokens
```

**Важно:** оба демо ходят в сеть и идут по 15–40 секунд. Вживую они в кадр
не влезут. Два варианта:

- **проще** — прогнать заранее, в кадре запустить и промотать/ускорить
  ожидание при монтаже;
- **честнее** — снять одним дублем и ускорить паузы в редакторе ×4.

Шрифт покрупнее, окно узкое. Уведомления выключить.

## Раскадровка

| Время | Что делаешь | Что в кадре |
|---|---|---|
| 0:00–0:03 | `python3 demo.py growth` | таблица начинает заполняться |
| 0:03–0:13 | *(ускорить при монтаже)* | восемь строк, колонка «нарастающим» растёт 54 → 725 |
| 0:13–0:16 | — | итог: **переплата за перечитывание 293 токена** |
| 0:16–0:19 | `python3 demo.py overflow` | заголовок, первая модель |
| 0:19–0:24 | *(ускорить)* | **`ОШИБКА 400: maximum context length is 60000`** |
| 0:24–0:30 | — | вторая модель: **«вход обрезан, молча»**, 103 476 символов → 1 122 токена |

## Что сказать

> «Считаю токены. Восемь реплик — вес запроса растёт линейно, а сумма
> квадратично: 293 токена переплаты только за то, что историю шлём заново.
> Теперь переполнение. Одна модель честно отвечает четырёхсотой ошибкой.
> А вторая — молча обрезает вход: сто тысяч символов и восемь тысяч дают
> одно и то же число, 1 122. Ошибки нет, ответ приходит нормальный.
> Агент потерял начало диалога и не знает об этом.»

Если без голоса — две подписи: **«счёт растёт квадратично»** в первой половине
и **«а здесь вход обрезали молча»** во второй.

## Если совсем не влезает

Выкинуть `growth`, оставить только `overflow` — это самый сильный кадр:
две модели, две разные поломки, и вторая страшнее первой. Тогда:

| Время | Что |
|---|---|
| 0:00–0:04 | `python3 demo.py overflow` |
| 0:04–0:14 | ошибка 400 крупно |
| 0:14–0:26 | строки «вход обрезан, молча»: 103 476 символов → 1 122 токена |
| 0:26–0:30 | вывод внизу экрана |

А рост счёта показать статикой — одним кадром таблицы из README.

## Версия на 1.5 минуты, если попросят длиннее

Добавить в начало разбор веса запроса — он объясняет, откуда вообще берутся
токены:

```bash
python3 cli.py
```
```
/вес
```

На экране:

```
  Следующий запрос весит ~190 токенов
    обвязка запроса        30
    роль                   58   ← уезжает в КАЖДОМ запросе
    история диалога       102   ← оплачивается заново
    сам вопрос              0
```

> «Вопрос ещё не задан, а запрос уже весит 190 токенов. Платим не за вопрос,
> а за роль и историю, которые уезжают заново каждый раз.»

Потом задать любой вопрос — после ответа видно, **насколько промахнулась
оценка**:

```
  вход 214 (оценка промахнулась на +8, 3.7%) · ответ 156 · $0.00006
```

> «Точного числа до отправки не знает никто — токенизатор это внешняя
> зависимость. Поэтому считаю оценкой и знаю, насколько она врёт: около
> шести процентов, всегда в большую сторону.»

## Ловушки

| Что может пойти не так | Что делать |
|---|---|
| `demo.py overflow` идёт долго | это нормально: шлём сотни тысяч символов. Ускорить при монтаже |
| `Не найден OPENROUTER_API_KEY` | `overflow` ходит в OpenRouter, ключ нужен в `.env` |
| Модель отвечает медленно | у DeepSeek бывают просадки до 30 с, это не зависание |
| Числа в `growth` отличаются от README | так и должно быть — ответы модели каждый раз разные |
| `gemma` вдруг вернула ошибку вместо усечения | провайдер сменил поведение; тогда сюжет «молча» показать на записи из README |
