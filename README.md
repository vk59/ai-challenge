# AI Advent Challenge — 9 поток

Репозиторий с заданиями челленджа. Один день — одна папка в `days/`, самодостаточная и запускаемая.

## Структура

```
.
├── days/                  # по папке на день, каждая запускается независимо
│   └── day-01-first-api-call/
│       ├── README.md      # условие задания + что сделано + как запустить
│       └── main.py
├── shared/                # общий код: llm.py — клиент к API (со дня 2)
├── docs/
│   ├── rules.md           # правила потока, дедлайны, чек-лист подготовки
│   └── submissions.md     # ссылки, которые сдаём в таблицу
├── deploy/                # конфиги/скрипты для VPS (пригодится ближе к деплою)
├── .env.example           # шаблон переменных окружения
└── .env                   # реальные ключи, в git НЕ попадает
```

**Почему так:** задания копятся ~20 штук, часть из них потом деплоится на VPS. Папка на день
даёт изолированный запускаемый артефакт (удобно снимать видео и давать ссылку в таблицу),
а `.env` в корне — один набор ключей на все дни, чтобы не плодить копии секретов.

## Быстрый старт

Внешних зависимостей пока нет — нужен только Python 3.10+.
Остаётся вписать ключи в `.env` (файл уже создан, в git не попадает):

```
DEEPSEEK_API_KEY=sk-...          # дни 1–5
OPENROUTER_API_KEY=sk-or-v1-...  # нужен со дня 5
```

Запуск дня:

```bash
cd days/day-01-first-api-call
python3 main.py "Привет! Кто ты?"   # CLI
python3 web.py                      # веб на http://127.0.0.1:8000
```

## Правила сдачи

Кратко: задания в 14:00 МСК по будням, все 5 за неделю — до понедельника 14:00 МСК,
сдача = комментарий со ссылками в свой слот таблицы. Подробности — в [docs/rules.md](docs/rules.md).
